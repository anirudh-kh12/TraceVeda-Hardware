# Before Publishing to GitHub

- [ ] Confirm with the TraceVeda team that this hardware-focused derivative repository is okay to publish.
- [ ] Confirm the applicable licence/permissions; the uploaded archive had no root `LICENSE`.
- [ ] Review all copied sketches for credentials and private endpoints.
- [ ] Compile both final integration sketches using the intended ESP32 board package and library versions.
- [ ] Verify pin maps against the actual assembled prototype.
- [ ] Add actual circuit/schematic drawings after verifying wiring.
- [ ] Add real prototype photographs and redact labels, credentials, or personal information if needed.
- [ ] Add measured test evidence; do not invent results.
- [ ] Review README team acknowledgements and role description.
- [ ] Create a new GitHub repository and upload this folder as a fresh repository (do not include the original `.git` directory).
