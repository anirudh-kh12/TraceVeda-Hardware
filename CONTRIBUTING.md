# Contribution and Documentation Rules

This is a hardware-focused portfolio repository for a collaborative project.

- Keep the final integration sketches in `firmware/Final_Integration/` synchronized with the canonical source files.
- Preserve earlier experiments under their original development-stage folders and label them clearly.
- Do not add claims of functionality unless supported by code and repeatable tests.
- Do not add circuit diagrams until the physical wiring and module variants are verified.
- Never commit Wi-Fi credentials, API keys, access tokens, or production endpoints.
- Record component tests with date, setup, procedure, actual observation, status, and evidence.
- Credit the TraceVeda team and link to the original team repository.
- Do not add or change a licence without permission from the relevant rights holders.
